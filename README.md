# PJZSoftware

面向个人的 Windows 本地记账与投资资产管理软件。项目暂名 PJZSoftware，当前已实现 0.3.0 日常账本便携版，投资管理与历史导入后续开发。

首版目标：离线记账、人民币账户、A 股／境内 ETF／公募基金管理，以及可验证的备份与换机恢复。按用户选择采用 **Next.js + FastAPI + SQLite**。

## 已确定的产品边界

- 账本留在本机；核心功能不需要联网、远程服务器或注册账号。
- 首版无需独立解锁密码，数据库和备份默认不做应用层加密，依赖 Windows 账户权限保护。
- 首版使用手动估值，不接行情、银行或券商账户，不代客交易。
- 旧账支持分类月度汇总；明确区分汇总与逐笔明细，避免重复入账。
- 代码与个人数据分离。GitHub 只管理代码、设计和合成测试样例。

## 仓库与本地数据

远端仓库：[WEIWEICurry/PJZSoftware](https://github.com/WEIWEICurry/PJZSoftware)。

本地 `data/` 存放迁移资料且被 Git 忽略。安装后运行时数据计划放在 Windows 用户数据目录下的独立账本文件夹，卸载或更新程序时不得删除账本。完整路径由应用显示并支持打开。

不要将个人截图、账本、交易记录、账户余额、备份或日志附到公开 Issue／PR。演示与测试只使用虚构数据。

## 当前状态

0.3.0 已实现账户、期初余额、收入／支出／退款、转账与手续费、借还本金、余额校正、修改／作废、账户归档、自定义分类与月收支总览。新增带影响预览和删除前备份的账户彻底删除，以及同分类前 5 条常用备注一键填充。金额使用整数分；每次财务写入包含幂等、版本校验、修订及现金时间线核对。

支持旧版账本升级前备份、schema v1→v2 的 Alembic 事务迁移，以及完整业务数据的备份恢复。真实截图尚未导入，投资持仓和预算尚未实现。

本地程序：dist/PJZSoftware/PJZSoftware.exe（保留整个目录）。使用方法、边界和验证命令见[运行指南](docs/07-running.md)。

本机后端 30 项测试与浏览器全流程通过；Windows CI 结果以实际检查为准。正式安装／卸载及独立标准账户验收尚待完成。
