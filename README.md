# PJZSoftware

面向个人的 Windows 本地记账与投资资产管理软件。项目暂名 PJZSoftware，当前 0.20.0 使用蓝白工作台界面：浅蓝导航与蓝色强调、统一金额层次和宽屏并排记账，保留安静启动、固定入口、本地更新与回退，以及现有账本与投资功能。

首版目标：离线记账、人民币账户、A 股／境内 ETF／公募基金管理，以及可验证的备份与换机恢复。按用户选择采用 **Next.js + FastAPI + SQLite**。

## 已确定的产品边界

- 账本留在本机；核心功能不需要联网、远程服务器或注册账号。
- 首版无需独立解锁密码，数据库和备份默认不做应用层加密，依赖 Windows 账户权限保护。
- 默认使用手动估值，可主动启用公开基金单位净值查询；不接银行或券商账户，不代客交易。
- 旧账支持分类月度汇总；明确区分汇总与逐笔明细，避免重复入账。
- 代码与个人数据分离。GitHub 只管理代码、设计和合成测试样例。

## 仓库与本地数据

远端仓库：[WEIWEICurry/PJZSoftware](https://github.com/WEIWEICurry/PJZSoftware)。

本地 `data/` 存放迁移资料且被 Git 忽略。安装后运行时数据计划放在 Windows 用户数据目录下的独立账本文件夹，卸载或更新程序时不得删除账本。完整路径由应用显示并支持打开。

不要将个人截图、账本、交易记录、账户余额、备份或日志附到公开 Issue／PR。演示与测试只使用虚构数据。

独立模块路径与刷新／历史导航说明见 [路由验收](docs/22-module-routes.md)。

## 0.18.0 持仓归属修正与升级

投资选择持仓账户（例如支付宝）和独立扣款／到账账户。同一平台同一标的跨银行卡买入合并核算。用户已完成历史整理，0.18.1 移除临时归并工具，已整理的数据、审计与备份保留。创建平台账户时，期初日期应不晚于投资历史，平台现金可为零。

已在使用 0.18.0 的用户可通过现有同 schema 更新管理选择 0.18.1 ZIP；无需再次安装独立入口。

**本次 schema 升级为 10。旧版更新管理只支持同 schema，不能直接选择本 ZIP 更新。** 请先在旧版下载备份并退出软件，解压完整新包运行 PJZSoftware.exe（使用原账本目录，非默认目录需指定 --data-dir）。程序在升级前自动保存保护备份。在新版“数据管理 → 启动与更新管理”设置固定入口并重新创建桌面快捷方式；新版使用独立 application-schema-10 入口，保留旧程序。原入口不能打开升级后的账本；需要回旧版时，将升级前备份恢复为独立副本，不能原地降级。

验收与限制见 [持仓／支付分离](docs/23-holding-payment.md)。

## 0.19.0 投资操作优化

“记一笔投资”支持再次点击收起，再展开保留草稿；取消编辑才清空。联网基金净值支持一次多选最多 10 只、统一日期范围、逐只预览及一次确认顺序导入；失败项独立重查，已成功项不重复提交。每只独立事务，不是跨基金整批原子导入；有效净值仍保护，离开页面不继续后续查询。定投操作栏使用有边框和底纹的按钮。schema 10 不变，0.18.x 可直接使用本地 ZIP 更新。详见 [验收](docs/25-investment-batch-nav.md)。

## 0.20.0 浏览器与加载页

Windows 启动优先读取系统 HTTP 默认浏览器程序直接打开；HTTP 无有效程序时尝试 HTTPS 默认及已安装浏览器备用，不修改系统默认设置。全部失败时显示原服务管理窗口。页面加载与账本连接时显示蓝白转圈页，成功即进入，不人为等待；失败可重新加载，长时间等待有提示，并尊重系统减少动画设置。动画不覆盖浏览器打开之前的本地程序启动阶段。schema 10 不变，可通过现有 ZIP 更新。详见 [验收](docs/27-browser-startup.md)。

## 当前状态

0.6.1 支持日／周／月／年收支汇总、分类排行、上期对比、构成明细和 CSV。选择器对应日期／周／月／年，日报不再重复显示单点趋势；其他周期使用横向时间柱图，支持键盘查看、正负值和窄屏图内滚动。截取历史汇总时保留未知值，不伪造分日数据。分类预算自愿按月设置，未配置不显示已用／剩余额度；支持调整、移除、超支提示和沿用上月，不限制记账。

支持投资标的、期初持仓、买卖／基金申赎、手动估值、移动加权成本、历史修改重算及含持仓的资产总览。缺价格／成本不填零，投资及费用不进入日常收支。支持现金分红、公募基金分红再投及拆分／合并，单列分红收益。事件后旧价格不用于新持仓估值，同日价格需再次确认；支持月／年／自选期间投资构成、当前配置分组及四类 CSV；支持按当前有效事实重建期初、期末持仓，边界当日估值齐全且无期间期初注入时计算期间总盈亏；缺价明确提示，当前总览提供非年化持仓／累计收益率，期间收益率与曲线后续。

支持每日／工作日／每周的基金定投计划、管理栏修改、暂停恢复及删除后只读历史、按范围生成不影响资产的待核对项，以及批量确认／跳过；实际确认份额与扣款由用户核对，整批事务入账。

支持默认每日自动备份（运行中每分钟检查变更、保留最近 14 份、失败提示与重试）、恢复前原子保护副本、升级前备份、schema v1～v9→v10 的 Alembic 事务迁移，以及包含投资、历史汇总、原始 JSON 和预算的备份恢复。真实资料不进入仓库；截图图片不包含在当前备份中，应保留原件。整段明细核对替换尚未实现。

首次运行：解压当前版本便携包后运行 PJZSoftware/PJZSoftware.exe（保留整个目录），先从旧程序选择“退出软件”。软件直接打开浏览器账本；在“数据管理 → 打开启动与更新管理”中设置固定入口并创建桌面“PJZ记账”。以后从同一个入口启动和选择本地 ZIP 更新；不要把解压包里的 PJZStart.exe 单独复制或直接当已安装入口运行。页面版本来自实际后端，当前应为 v0.20.0。使用方法、限制和验证命令见[运行指南](docs/07-running.md)。

验证记录见 M3.1 实施文档；CI 结果以实际检查为准。正式安装／卸载及独立标准账户验收尚待完成。
