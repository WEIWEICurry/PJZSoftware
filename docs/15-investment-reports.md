# M3.3 第一阶段：期间报表、当前配置与 CSV

状态：M3.3 第一阶段已实现，0.9.0 待 PR 合并。

## 范围与口径

独立投资报表入口，支持月、年和自选起止日期，当前期间截至今天。按持仓所属账户、标的、股票／ETF／公募基金筛选。先按日期和 sequence 重放全部有效历史，再归属期间，不在期间开始时清零成本。仅有效事件计入报表，明细可包含作废；作废不影响统计。

指标：买入／申购实际扣款（含费用）、卖出／赎回净到账、已实现卖出盈亏、现金净分红、再投净分红、已计入成本或净到账的费用。已实现＋分红合计仅是收益构成，不含浮动盈亏，不命名为期间总收益；费用仅展示，不能再次扣除。另列相关投资事件现金净变动，不等于账户余额变化，不含普通转账／收支／期初。现金分红可到账另一个账户，筛选仍按持仓所属账户归属。

按标的汇总收益构成，明细分页、可查看分摊成本、实际现金变动及分红到账账户。期间外买入参与成本重放但不混入当期买入金额，历史修改和作废后同一规则重算。

当前配置单独标注，不是期间期末快照：按标的／账户／投资类型归组，只包括当前未清仓持仓。金额由最新有效手动价格计算，保留各组价格日期范围。筛选只改变展示范围，占比分母仍为全部持仓总市值，不含现金；全局缺估值时占比未知，组内缺估值时显示已知小计与未知总值，零总值不除零。成本未知不阻止可估值的配置。不能根据基金名称猜测行业或穿透持股。

## CSV 与一致性

四类 CSV：期间报表（有效事件汇总与标的构成）、投资记录（期间内全部分页，沿用是否包含作废）、当前未清仓持仓（不受日期限制）、手动估值（期间内且始终包含作废）。估值本身不属于某账户，选账户时只导出该账户存在投资记录的标的，含已清仓历史；类型和标的筛选继续有效。

CSV 使用 UTF-8 BOM，保留记录／标的／账户 ID、revision、日期、状态、整数分及可读元金额；未知留空并附状态，不写零。用户名称与备注防公式注入；数字由可信整数／Decimal 格式化，不把负数当作恶意文本。代码在文件中保留前导零，Excel 应按文本导入，不用公式强制代码类型。单次最多 50000 数据行，超限拒绝而非截断。

各响应、汇总、当前配置和导出均在各自同一个 SQLite 读事务内计算，返回账本 revision；下载按当时账本重新计算，未承诺与之前屏幕版本锁定，CSV 带版本与范围可追溯。金融金额不用前端浮点计算，比例使用后端 Decimal。schema v7 不变，无新增数据库迁移；不写真实账本，不创建额外快照余额。

## 验收

1. 独立手算：期间外买入的移动成本正确计入期间内卖出；按账户分别核算，同一标的多账户汇总不串成本。
2. 净额买卖、手续费、现金分红、再投另付费用、拆分、期初、作废均按上述口径；不重复扣费，普通收支与预算不受影响。
3. 月／年／闰年与自选区间，当前期间截断、无记录、无效／未来起点、起止倒置及不存在的筛选对象验证；期间合计与全量明细一致，分页不改变总额。
4. 配置的不同分组、筛选不改占比分母、缺价格、事件后待估值、未知成本、零市值、清仓及不同价格日期正确展示；明确是当前配置。
5. 四类 CSV 与所选范围一致、包含全部分页、作废和未知可追溯、精确金额、引号／换行／中文及公式注入、超限拒绝；代码前导零保留。
6. 查询与导出前后账本版本、现金及持仓不变；合成浏览器验证期间选择、筛选、配置切换与四类下载；Windows 成品自检及断开开发 PATH 探测。
