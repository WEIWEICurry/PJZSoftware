# 页面与操作流程

## 1. 交互原则

桌面中文界面，优先适配 1280×800 及以上窗口；键盘可完成记账；金额右对齐、保留两位小数，正负与状态不只靠颜色区分。首次打开空白账本，不自动生成真实记录或联网。

左侧导航：总览、日常账本、账户、投资、报表与预算、数据管理、设置。页顶始终可见账本名与“记一笔”，全局筛选明确期间。

## 2. 页面设计

| 页面 | 主要内容 | 主要操作 |
| --- | --- | --- |
| 总览 | 净资产、可用现金、投资估值、负债、本月收支；估值缺失提示 | 记一笔、更新估值、查看账户 |
| 日常账本 | 明细表，按日期／分类／账户／收支类型筛选；历史汇总另一个页签 | 新增、修改、作废、导出 |
| 账户 | 账户列表、当前余额、期初日期、余额变动明细 | 新建、转账、录期初、校正、归档 |
| 投资 | 持仓与交易两页签；数量、剩余成本、最新价日期、估值、盈亏 | 买入、卖出、分红、再投、更新价格 |
| 投资详情 | 单个标的的交易时间线、费用、成本变化、盈亏构成 | 修改交易、录入证券事件 |
| 报表与预算 | 月收支趋势、分类分布、预算执行、投资盈亏单列 | 切换期间、查看统计口径 |
| 数据管理 | 导入批次、核对差异、备份恢复、开放导出、数据目录 | 预览导入、备份、验证／恢复 |
| 设置 | 本地目录说明、显示格式、备份策略、版本 | 打开目录、设置备份目标 |

总览的净资产在估值缺失时显示“部分资产待估值”，同时展示已估值小计，不展示无条件的完整净资产。历史月度汇总不出现在账户流水中。

## 3. 关键流程

### 首次使用

创建账本 → 选择数据位置（默认用户数据目录）→ 建账户与期初余额 → 可选择导入旧账汇总 → 开始记账。期初日期与旧账汇总期间独立，说明汇总不会反推历史余额。首页显示数据存放位置及未启用应用加密状态。

### 记一笔

选择支出／收入／转账 → 日期、金额、账户、分类、备注 → 校验 → 保存成功后刷新余额与列表。连续点击只保存一次；错误保留表单，明确标出字段。日期默认本地日历日；允许补录，未来日常流水首版不作为已发生记录保存。

### 投资买卖

选择证券账户和标的 → 填成交／确认日期、份额、成交总额、费用，可辅助填写单价 → 展示现金变化和预计持仓 → 保存。公募基金使用确认份额与实际确认金额，未确认申购暂不计入持仓；如已扣款，提示首版需在确认后补录，不能宣称期间现金已精确反映。

单价乘数量与实际金额有差异时由用户确认实际成交总额，不能悄悄改费用。卖出超过当时持仓、录入后续交易失效、资金不足时给出具体提示。

### 历史汇总导入

选择文件 → 展示期间、分类、金额、来源和差异 → 匹配分类 → 显示与现有汇总／明细的冲突 → 一次事务导入 → 可查看批次或撤销。导入属于报表历史数据，不选择虚假的支付账户。

### 备份与换机

选择备份位置 → 生成并验证 → 显示路径、时间和校验结果。新电脑安装 → 选择恢复包 → 预览账本、版本和记录数量 → 在新的账本目录恢复并核验 → 切换账本。已有账本不被静默覆盖。

## 4. 必须设计的状态

空白、加载、无筛选结果、输入错误、余额不足、无价格、价格过旧、导入冲突、备份失败、磁盘不足、只读目录、数据库损坏、迁移失败、不支持的新格式。错误不泄露原始交易到日志；提供可执行的下一步。

删除有记录的账户／分类用归档；交易用作废并保留本地操作记录。恢复、撤销导入等影响大量记录的操作先预览影响范围，再由用户执行。
