# 蓝白工作台配色（0.19.1）

## 验收

用户要求参考支付宝的清爽蓝色感，沿用现有布局与交互。侧栏改为浅蓝白底、深蓝文字与淡蓝选中态；主按钮、页签、焦点、备注建议和定投操作采用统一蓝色。主要按钮使用较深蓝以保持白字清晰，大面积背景使用低饱和蓝灰，避免整页高亮蓝。

投资盈利红、亏损绿、危险红、警告橙、成功提示的语义颜色保留，避免主题切换改变金额含义。表格、报表与预算轨道、模态背景、输入边框及辅助文字协调更新。

只调整 CSS 颜色和相关说明，不改变数据、计算、路由或 API 行为。schema 10 不变。主按钮白字和导航正文对比度至少 4.5:1，键盘焦点可见；桌面与窄屏合成截图复核投资、记账、净值与定投页面，既有浏览器流程通过。无外部字体、图片、品牌标志或新增依赖。

## 本地验证

Ruff 检查／格式、mypy、264 项 pytest；前端格式、ESLint、类型检查、静态构建、6 项 Playwright；契约同步与应用自检均通过。已复核桌面投资、定投及窄屏记账合成截图。对比度：主按钮白字 5.42:1，导航正文 7.44:1，选中导航 5.40:1，白底辅助文字 4.69:1。金融盈亏变量保持原值。成品与 CI 最终状态见 PR。
