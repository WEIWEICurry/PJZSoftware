# 青松工作台界面改造

## 范围与验收条件

本次只调整正式前端的视觉与布局，沿用 Next.js、现有 API 和账务规则；不改变数据库、净值来源、成本或收益率计算，不新增联网资源。

- 深绿侧栏按“生活账本、投资资产、工作空间”分组；所有现有页面仍可到达，当前页面有文字及选中标记。
- 页面使用直接的中文标题，移除英文装饰口号和开发阶段徽章；保留版本、本地状态、退出及启动更新管理。
- 正文与输入为 16px，表格和标签至少 15px，辅助文字至少 13px；统一浅色背景、卡片、按钮、输入与键盘焦点。
- 投资市值卡突出显示，金额使用等宽数字，持仓数值列右对齐；盈亏颜色与数值正负同时表达，未知值不填零。收益率、排序及筛选保留。
- 1280px 及以上记账表单与流水并排；较窄窗口上下排列。转账、借还款、退款、修改和分类常用备注完整保留。
- 390px、1280px、1440px 窗口均可导航和操作；长表仅在容器内滚动，不撑宽整页；长名称、空白、错误和缺估值状态可读。
- 报表、预算、账户、定投及备份恢复沿用统一组件样式；预算仍按需设置。
- 自动验证覆盖导航可达、窄屏无整页溢出、桌面记账并排与窄屏回落；既有账务端到端测试继续通过。截图只使用合成数据。

## 设计决定

使用 CSS 变量集中管理青松配色；导航采用仓库内 SVG 图标，避免远程字体和图标依赖。日常表单仅重排现有 DOM，不复制业务组件或计算。宽屏记账侧栏保持普通文档流，避免长借还款表单被固定定位遮挡。表格保留语义与排序按钮，颜色只作辅助。

## 验证记录

已在 Windows 本机执行：Ruff 检查与格式、mypy、pytest（261 项通过）；前端 Prettier、ESLint、类型检查、静态构建、Playwright（4 项通过，包含 390／900／1280／1440／1920px 合成页面检查及导航、排序、借还款、投资、备份恢复流程）；契约同步检查与应用自检均通过。

合成截图人工复核覆盖宽屏记账、窄屏导航与表格、投资持仓及估值页。发行成品与 GitHub CI 的最终状态以 PR 记录为准。

已知限制：宽度不足时长表需要在表内横向滚动；本次没有增加深色内容主题或手机专用导航。
