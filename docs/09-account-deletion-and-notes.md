# 归档账户彻底删除与分类常用备注

## 账户删除

用户明确要求增加彻底删除，以替代只归档。仅对已归档、余额为零的账户提供该入口。删除会从当前账本物理移除账户、其作为任一端的流水、相关现金分录及依赖这些支出的退款，包含已作废记录和期初。关联转账从两端一并移除，不能保留半笔。

执行前必须预览：流水数量、关联退款和转账数量、受影响其他账户及余额变化。确认需输入完整账户名称；预览 120 秒有效，绑定账本 revision，数据变化后必须重做预览。删除前创建并验证完整备份，备份失败不删除。旧备份仍含原数据，删除不是磁盘取证意义的擦除；界面说明不能在软件内撤销，可用备份恢复。

预览用事务保存点模拟删除并完整重放剩余现金时间线，然后回滚。若影响其他账户的历史余额或关联规则，显示不可执行及原因，不允许越过校验。确认删除、清理引用、重建现金分录、最小删除凭证和幂等记录同事务提交，失败整体回滚。

与删除对象相关的旧修订 JSON 从当前账本移除；含已删除对象的历史幂等结果改为不含财务内容的失效标记。旧请求不能通过重试重新创建账户或返回旧流水内容。删除凭证只记匿名 ID、数量和备份文件名，不重复保存账户名称或交易备注。未关联的账户、流水和修订保持不变。

删除普通表时启用 secure_delete，新备份快照经过 VACUUM 压实，避免复制空闲页旧文本；这不等于清除旧备份或磁盘日志。

此变更不改表结构，继续使用 schema v2；历史备份可按已有恢复流程恢复。

## 常用备注

在备注输入框下方显示所选分类最常用的 5 个非空备注。来源为本地已保存、未作废且分类匹配的流水，前后空白规范化，同名合并，按使用次数降序，次数相同按最近保存／修改时间降序，再稳定排序。

点击备注按钮只填入文本，不提交表单、不改变分类或金额，支持键盘。空分类／无历史时不显示；切换分类立即撤下旧建议，忽略过期响应；保存、修改、作废或删除后重新统计。重启后从账本恢复统计，不使用浏览器本地存储或联网学习。

## 验收

- 空白或仅期初的归档账户删除后在当前账本不存在；取消预览不改变账本。
- 有流水时明确预览相关交易与其他账户影响，删除后外键、现金投影与报表一致。
- 删除导致其他账户任意时点余额不足时阻止；未归档、过期、名称不符、备份失败均不能删除。
- 响应丢失重试不重复备份或删除；旧新增／编辑请求重放返回资源已删除。
- 删除前备份可恢复完整账户与流水；无关记录不被清理。
- 备注跨分类隔离、频次／最近使用排序、过滤空白和作废、点击不提交、修改后更新及重启保持正确。
