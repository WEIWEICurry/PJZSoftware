# 默认浏览器与页面启动动画（0.20.0）

## 验收

Windows 不再把本地 http 链接交给可能弹出选择器的通用 webbrowser.open。通过系统协议关联查询实际可执行程序，优先 HTTP 默认，再尝试 HTTPS 默认；无有效关联时按已安装 Edge／Chrome／Firefox 作为备用，不修改注册表或系统默认项。找不到可用程序或启动失败则返回失败，沿用原服务管理窗口的打开／退出回退。

程序只传递既有本地地址及片段令牌，不打印 URL 或令牌；命令参数数组执行，shell=False，不执行注册表中的命令模板。屏蔽 OpenWith／rundll32 等选择器或代理程序，备用路径均为已安装程序。

页面静态导出时即包含蓝白加载页与转圈，不人为等待；会话建立和账本信息读取完成后进入工作台。等待较久提示检查服务，失败显示错误与重新加载按钮，尊重减少动画设置。此动画覆盖浏览器加载与账本连接，不覆盖打开浏览器之前的 Python 启动时间。

保持回环监听、会话保护、片段令牌清理、单实例、无浏览器模式、安静启动和退出行为。测试模拟协议关联／可执行文件／失败，不打开真实浏览器；合成页面延迟会话验证加载、进入与错误重试。schema 10 不变。

Windows 查询依据：[AssocQueryStringW](https://learn.microsoft.com/en-us/windows/win32/api/shlwapi/nf-shlwapi-assocquerystringw)。

## 本地验证

Ruff 检查与格式、mypy、269 项 pytest；前端格式、ESLint、类型检查、静态构建、8 项 Playwright；契约同步与应用自检通过。新增五项模拟浏览器关联／选择器跳过／备用／失败用例，不启动真实浏览器；新增两项合成浏览器测试覆盖静态加载页、延迟会话、减少动画和失败重试。加载页截图已复核。本机只读协议查询返回 msedge.exe，未改系统设置。成品与 CI 最终结果见 PR。
