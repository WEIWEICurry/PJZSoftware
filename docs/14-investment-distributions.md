# M3.2 分红与份额事件

状态：M3.2 已实现，0.8.0 待 PR 合并。

## 操作和口径

- 现金分红：填实际到账日、实际净到账金额与到账资金账户（默认持仓账户）。份额和成本不变；单列投资分红，不进入日常收入或预算。允许已有交易历史但已清仓的持仓收到延迟分红；不自动计算权益登记或税费。
- 基金分红再投：仅公募基金；填确认日、净再投分红金额、实际新增份额。分红收益及成本同时增加，现金净变化为零。若另从资金账户付费，单列另付费用并计入成本，只扣一次；已经包含在净分红中的代扣费用不再填写。
- 份额折算（拆分／合并）：放在操作列表“更多”分组；按平台实际确认的折算前、折算后份额录入，必须写明依据。前份额必须等于当日事件前重放份额，后份额正数且不同；成本不变、不产生收益或现金。使用确认前后份额避免比例除不尽时编造零碎份额；不支持现金补差或股票送红股，不能以折算掩盖其他事件。
- 同日按录入 sequence 执行。分红和折算须对应已有有效投资历史，基金再投及折算可在期初成本未知时记录，但盈亏仍未知，后续卖出前需补齐成本。

净分红＝现金分红＋再投分红；累计投资盈亏＝已实现卖出盈亏＋净分红＋未实现盈亏，另付再投费用已进入成本，不能再次减去。现金分红不摊薄剩余成本。

分红／再投／折算后，有持仓的标的只使用该事件日或之后的手动日终价格，明确要求除息／折算后价格。同日已有价格也需在事件保存后重新保存确认；更早价格保留可查看，但不计算当前市值、盈亏或占比，避免旧价配新份额制造虚假收益。事件日期为实际到账／确认日，属于保守估值门槛，不自动推断实际除息日期。同一标的多个账户分别录入事件，不自动更改其他账户份额。

## 数据与安全

schema v7 扩展 investment_events 的 action，新增 cash_account_id（仅现金分红）与 split_from_quantity（仅折算）。quantity 在现金分红固定为 "0"，折算表示确认后份额，其余含义沿用 v6。旧字段 gross_fen 在分红中表示实际净分红；现金分红费用必须零，再投 costs_fen 表示另外支付的费用。旧买卖行为保持。

投资收益和估值门槛均为重放投影，不保存第二份余额。父事件、子事实、现金分录、审计、版本和幂等同事务；修改或作废重算完整时间线，失败全部回滚，并指出冲突记录。收款账户的类型、归档、期初日期与资金历史均须校验；删除保护覆盖分红收款账户。升级前验证备份，旧 v1～v6 独立恢复后升级，回退仅用旧程序＋升级前备份副本。

## 验收

1. 合成期初 1000 份、成本 2100 元、价格 2.10 元；现金分红 100 元、事件后价格 2.00 元：现金增加 100，持仓 2000，累计盈亏为零，净资产不因分红虚增。
2. 同样期初选择再投 100 元新增 50 份：份额 1050、成本 2200，现金不变，按 2 元估值 2100，分红收益 100，累计盈亏零；另付 2 元时成本 2202、现金减少 2，累计盈亏 -2。
3. 1000→2000 的折算及反向合并，成本不变；旧价格不再用于市值，补录对应新价格后总价值不变。基金小数份额不静默舍入。
4. 分红与普通收支、预算互不混入；收款账户可不同于持仓账户，借还款或归档账户不能收款，早于收款账户期初拒绝；已清仓延迟现金分红可记录。
5. 未知成本保留未知；无历史分红、非基金再投、零金额、折算前份额不符、无依据、无效组合拒绝。缺估值或零总值不伪造占比。
6. 修改／作废分红引发后续现金不足、作废再投或修改折算破坏后续卖出时整体回滚；版本冲突、失响应重试只有一笔。
7. v6→v7 失败回滚且保留验证备份；旧买卖／退款关系不丢；含新事件备份恢复后现金、份额、成本、分红及盈亏一致，损坏分红关联拒绝。
8. 合成浏览器验证三类事件、修改／作废、估值提示、明细与分红展示；实际 Windows exe 在独立目录通过自检和运行探测。

## 验证记录与限制

本地 128 项后端测试通过（M3.2 新增 21 项含参数化场景），Ruff／格式、mypy、契约同步、前端 Prettier／ESLint／类型检查与静态构建通过。完整浏览器流程及排序／日期共 4 项测试通过，包含现金分红丢响应重试、再投另付费用、折算、修改／作废及价格确认。排序合成响应更新后另做对应回归。合成页面已目视检查，不包含个人数据。

0.8.0 在独立目录完成 PyInstaller 构建、实际 exe 自检和精简 PATH 的 package_probe，包含三类事件的现金、成本、分红、份额和恢复一致性核对；ZIP 与 SHA256 已验证。CI 结果以当前 PR 检查为准。旧程序目录和真实账本未作为本次验收数据。

当前仍不处理分红权益登记、预扣税推算、送红股、现金补差、投资期间报表／CSV（M3.3），也不自动抓取价格。对同日事件修改采用重新确认价格的保守口径，包括仅修改备注。价格、账务日期均由用户按平台确认记录提供，不承诺与平台摊薄成本的展示口径一致。
