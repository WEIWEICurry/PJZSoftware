# M4.1 自动备份与恢复保障

## 范围与验收（实现前确定）

- 默认启用，无网络；账本目录 backups/automatic/ 保存自然日备份。启动、运行中每 60 秒及正常退出检查；账本 revision 变化更新当天副本，跨日无变更不重复备份。第一次运行生成基线。当天后续写入更新同一日副本，非每笔历史快照；尚未备份期间最多约一分钟，强制结束不保证最后一次写入已备份。
- 仅在 SQLite Backup API 快照通过格式、哈希、完整性与业务校验后，以同目录临时文件、fsync、原子替换发布。旧副本失败不丢失，不删除唯一副本。
- 保留最近 14 个已验证的成功每日文件；新文件发布成功后才轮转。只处理本功能专属目录的严格日期名称，不跟随符号链接，不删除手动／升级前／恢复前备份，也不删除异常文件。
- 数据管理展示最近成功时间、已备份与当前 revision、待备份状态、保留份数、固定目录、最近副本列表及下载；全局失败提示，错误仅显示分类，无敏感日志。失败重启后通过再次检查恢复状态，可主动重试，失败不阻止记账。目录选择与自定义保留期后续，不开放任意文件路径接口。
- 同一份快照生成 manifest 的 schema、账本 ID 和 revision，不能混用实时账本信息。旧 format v1 兼容，数据库 schema v9 不变。
- 恢复前保护副本使用相同验证和原子发布，命名 before-restore-随机ID；保护副本失败则不创建恢复目录。恢复始终在新目录验证、迁移再发布；失败保留当前账本、原恢复包及安全副本。独立副本切换仍通过启动器 --data-dir，页面提供说明，不自动替换运行中的唯一账本。
- 自动备份与账本同盘，仅保障误操作／程序故障，不保障整盘损坏；提供下载用于外部备份。备份未加密且不含原截图图片，真实资料不用于验收。

## 验证要求

合成账本验证同日变更、跨日无变更／有变更、重启、长时间运行、正常退出、保留 14 份、非自动备份保留；磁盘写入／校验／替换／清理失败不丢旧文件、失败可重试、临时文件不冒充成功；损坏文件、路径穿越和符号链接拒绝；并发写入快照与 manifest 一致；WAL 状态、现金及投资报表备份恢复一致。API 认证／Host／Origin／CSRF 及固定 ID 边界，浏览器状态与重试／下载，Windows 成品验证。实际结果在交付时记录。

## 0.15.0 实际验证

完整 219 项后端测试通过，新增 16 项自动备份验收包含失败注入、轮转、重启、周期及退出检查、并发提交快照、损坏保留、目录链接／其他账本隔离、恢复前失败和合成投资账本完整恢复。4 项浏览器测试通过，扩展失败提示、重试、历史副本下载及恢复；合成页面已目视检查。Ruff／格式、mypy、契约同步、Prettier、ESLint、类型及静态构建通过。实际 Windows exe 自检与精简 PATH 探测通过，含启动自动备份、单实例及强制结束后恢复；ZIP 与校验文件在交付时生成。CI 以当前 PR 实际结果为准。

不包含截图附件、加密、自定义目录、系统未运行时的计划任务或一键切换运行账本。损坏的当日文件重新备份时移至 damaged-随机ID 保留；保留份数仅统计可用每日副本，异常文件不被自动清理。备份大小仍受原格式 8 MB 上限约束，超过上限明确失败，不以成功状态掩盖。
