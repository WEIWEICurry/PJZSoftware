# 定投计划与批量确认（0.12.0）

状态：0.12.0 已实现，待 PR 合并。

## 纵向范围

人民币公募基金计划保存名称、资金账户、标的、起始日、单次实际扣款与默认费用，支持每日／周一至周五／每周指定星期，暂停与恢复。显式选择最多 366 天生成草稿，未来日期不生成；星期规则不是市场交易日历，节假日及暂停申购需人工跳过。暂停仅阻止新生成，恢复不会后台补单。每计划＋日期唯一，跳过及已确认均不重新生成；已生成金额保持当时快照。计划首版不支持修改身份／金额，变更需暂停原计划并建立新计划。

草稿不是实际扣款，不冻结资金、不改变现金／份额／收支。单批最多 100 项，填写确认日期、实际确认份额、实际扣款、费用，可附净值所属日（不晚于确认日）；确认日期不早于计划日期、不晚于今天。份额不通过最新净值猜测。确认前预览所选总扣款和行数；确认后生成原有 buy 事件，实际扣款已含费用。重复计划日、幂等重试或已确认项不重复入账。与现有同账户／标的／确认日／份额／实际扣款完全相同的有效买入默认拒绝，只有明确核对后才能允许。

一批确认在同一事务插入并重放完整现金／持仓；任一项失败整批回滚，拒绝资金不足、归档／借还账户和冲突版本。跳过不会影响现金。已确认项关联真实事件，日后通过原投资记录修改／作废；作废后计划项仍保留关联并显示作废，不能重新生成同日项。首版不记待确认资金在途，不接支付宝、不联网计算交易份额、不自动后台扣款或确认。

## 数据与验收

schema v8 增加 investment_plans 与 investment_drafts，外键关联账户／标的／事件，升级前备份，事务迁移，完整备份恢复包含计划与草稿。包含计划的账户不得彻底删除，防止破坏关联；仍可归档但无法新生成或确认。旧版本不能打开 v8，回退需恢复升级前备份到单独目录。

验收：纯日期算例覆盖周末、跨月／闰年和范围；重复生成、暂停恢复、跳过、并发版本与双重确认；独立手算两笔 10 元含费用买入核对现金／成本／份额，资金不足整批回滚，疑似重复警告，作废关联；备份恢复与 v7→v8 升级备份；合成浏览器完成建计划→生成→填写份额→确认→原投资记录核对，已有全部检查与 Windows 成品验证通过后交付。

## 实现验证记录

本地完整 191 项后端测试通过，其中新增 17 项定投验收；包含两笔含费用的 10 元买入独立核对、资金不足整批回滚、重复生成／确认、疑似手工重复、暂停／跳过／作废、非法字段、恢复与 v7 升级，以及迁移中断回滚。4 项浏览器测试通过，实际完成建计划→生成→填写份额→预览→确认→原交易作废；合成截图已检查。格式、静态、类型与契约验证通过。成品自检已扩展实际本地 HTTP 定投确认，后续 Windows 与 CI 以实际检查为准。

限制：不处理待确认资金在途；按确认日记现金，无法重建扣款日至确认日的在途资金。每周／工作日规则仅生成建议日期，不是交易日历。计划首版不支持修改参数、删除、跳过撤销或绑定既有交易；变更需暂停旧计划新建，误跳过的真实交易通过原记一笔投资补录。已确认事件继续由原投资记录纠错。
