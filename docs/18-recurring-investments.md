# 定投计划与批量确认（0.12.0）

状态：0.12.0 已实现，待 PR 合并。

## 纵向范围

人民币公募基金计划保存名称、资金账户、标的、起始日、单次实际扣款与默认费用，支持每日／周一至周五／每周指定星期，暂停与恢复。显式选择最多 366 天生成草稿，未来日期不生成；星期规则不是市场交易日历，节假日及暂停申购需人工跳过。暂停仅阻止新生成，恢复不会后台补单。每计划＋日期唯一，跳过及已确认均不重新生成；已生成金额保持当时快照。0.12.0 首版变更需新建计划；0.13.0 管理与修改见下节。

草稿不是实际扣款，不冻结资金、不改变现金／份额／收支。单批最多 100 项，填写确认日期、实际确认份额、实际扣款、费用，可附净值所属日（不晚于确认日）；确认日期不早于计划日期、不晚于今天。份额不通过最新净值猜测。确认前预览所选总扣款和行数；确认后生成原有 buy 事件，实际扣款已含费用。重复计划日、幂等重试或已确认项不重复入账。与现有同账户／标的／确认日／份额／实际扣款完全相同的有效买入默认拒绝，只有明确核对后才能允许。

一批确认在同一事务插入并重放完整现金／持仓；任一项失败整批回滚，拒绝资金不足、归档／借还账户和冲突版本。跳过不会影响现金。已确认项关联真实事件，日后通过原投资记录修改／作废；作废后计划项仍保留关联并显示作废，不能重新生成同日项。首版不记待确认资金在途，不接支付宝、不联网计算交易份额、不自动后台扣款或确认。

## 数据与验收

schema v8 增加 investment_plans 与 investment_drafts，外键关联账户／标的／事件，升级前备份，事务迁移，完整备份恢复包含计划与草稿。包含计划的账户不得彻底删除，防止破坏关联；仍可归档但无法新生成或确认。旧版本不能打开 v8，回退需恢复升级前备份到单独目录。

验收：纯日期算例覆盖周末、跨月／闰年和范围；重复生成、暂停恢复、跳过、并发版本与双重确认；独立手算两笔 10 元含费用买入核对现金／成本／份额，资金不足整批回滚，疑似重复警告，作废关联；备份恢复与 v7→v8 升级备份；合成浏览器完成建计划→生成→填写份额→确认→原投资记录核对，已有全部检查与 Windows 成品验证通过后交付。

限制：不处理待确认资金在途；按确认日记现金，无法重建扣款日至确认日的在途资金。每周／工作日规则仅生成建议日期，不是交易日历。0.13.0 已扩展管理栏修改与删除，仍不支持跳过撤销或绑定既有交易；误跳过的真实交易通过原记一笔投资补录。已确认事件继续由原投资记录纠错。

## 0.13.0 管理与 QDII 验收（实现前确定）

管理栏列出全部未删除计划，可修改名称、金额、默认费用、频率；已有草稿后账户／基金／起始日锁定，避免改写关联历史。修改只影响未来新生成的草稿，已有草稿金额与已确认交易不变。保存成功收起表单；失败保留输入。

已暂停计划可删除，需二次确认；schema v9 增加 deleted 标记。删除从正常管理和选择列表移除，不删除草稿／交易／审计，可勾选查看已删除计划只读历史，不能再生成或确认。保留关联，保护既有账务、备份和重复记录边界。升级前备份，v8→v9 保留全部计划及关联，迁移失败回滚。

QDII 不按名称猜测固定 T+2／T+3，不自动推算交易日。计划日期为建议申请日期，实际确认日与成交净值所属日新确认时均需明确填写，确认日期不早于计划日期且不晚于今天，成交净值所属日不晚于确认日；计划日期只是建议，不据此推断平台有效申请日。旧确认记录未记净值日时显示未记录，不补造日期。价格只显示对应净值所属日的本地有效净值，不用确认日、最新价或邻近日期替代；缺价显示本地暂无，可联网补齐，但仍以平台确认份额与费用入账，不根据参考净值猜测份额。净值披露延迟不改变净值所属日，当前持仓估值仍显示所用净值真实日期。

依据：https://edu.gffunds.com.cn/lcxt/zdjptzjhl/tzjhl1/202504/t20250418_413106.shtml 。验收覆盖编辑后历史不变、身份锁定、暂停删除／冲突版本／已删除不可写、备份恢复和 v8 升级；延迟确认跨月／周末，精确日期净值匹配、仅有其他日期时未知，旧记录兼容；合成浏览器覆盖管理编辑删除与表单收起。
