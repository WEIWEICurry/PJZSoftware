# 定投待核对表布局

## 验收条件

- 计划日期和选择框在同一行，不拆分年月日；处理下拉完整显示“确认买入”。
- 为前两列、日期控件及净值核对列分配独立宽度，金额和份额输入框收紧到列宽。
- 宽屏均匀利用表格空间，窄窗口在表格内部横向滚动，不挤压日期或造成整页横向溢出。
- 不缩小字号、不隐藏操作或数据、不改变核对/确认逻辑。schema 11 不变。
- 使用合成待核对记录，在宽屏与窄窗口实际浏览器验证日期单行、选择框宽度、横向滚动与可操作性。

## 实现与验证

待核对表使用独立样式和八列列宽，最小宽度 1460px，表内横向滚动。计划日期和表头不换行，处理下拉保留至少 140px，金额/份额输入受各自列宽约束。布局不影响定投管理表和其他投资表。

274 项后端、10 项浏览器测试通过；端到端在 1920px 和 1100px 窗口检查日期单行、下拉宽度、窄窗口仅表内滚动且整页不横向溢出，并实际完成确认流程。已查看合成数据截图验证宽窄窗口布局。Ruff/格式、mypy、ESLint、TypeScript、Prettier、契约、静态构建和应用自检通过。
