# 日周月年报表与可选分类预算

## 范围与验收条件

新增“报表与预算”：日、周、月、年切换，选择日期、前后期间及返回当前期间；收入、净支出、结余、日均净支出、上期对比、趋势、分类排行、构成明细分页与 CSV。周为周一至周日，年度为自然年；当前期间截止今天，不填未来零值。上期对比：已结束期间比较整个上期，未结束期间比较上期相同经过天数（不越过上期末），展示实际对比日期；上期为零不计算百分比。

所有统计只反映已记录资料，不宣称空白日期无收支。退款抵减发生日支出，转账费用计支出；本金、借还款、期初、校正、作废不计入收支。完整包含的历史汇总与被覆盖明细只计一次。截取汇总期间时，该方向总额及相关分类显示未知，另列可定位的已知小计与来源；不分摊、不采用汇总减已知明细补差。月总额可统计但每日趋势可未知，年报按月展示；未来趋势显示未到日期。不同方向分别判断，支出未知不掩盖已知收入。构成明细标注有效、已被汇总覆盖及无法分配的原汇总；导出保持相同规则，不把原汇总金额伪装成日／周金额。

分类排行按净额排列，允许净退款为负；占比只对同方向正金额按精确比例计算，负净额不画为正消费。构成详情可按分类及方向查看，保留来源和范围，无任意账户归属推断。CSV 为 UTF-8 BOM，文本防公式注入，数值用十进制文本，包含所选期间、原记录期间、来源、金额及统计状态；超过 50000 行拒绝，不静默截断。

## 可选预算

仅月度支出分类预算，无默认额度、强制设置、自动结转或自动续期。未设置时不显示已用、剩余、百分比、超支等额度信息，只有可选设置入口；仅对已配置分类显示额度卡。预算按全账本月度净支出使用，与报表当前选中的日／周／年无关。退款降低已用，净支出低于零时已用以零为下限，不增加预算额度；剩余可为负，显示为超支。80% 标为接近额度，超过 100% 标为超支；不限制正常记账。

恰好 100% 显示额度用尽。对比比例以上期绝对值为分母；负上期结余可比较改善金额，上期为零不计算比例。日均以所选期间已过自然日天数计算，不只除以有流水的天数。

可选择预算月份、设置／修改正金额、移除及沿用上月。沿用只补充本月未设置的分类，不覆盖已设置额度；用户明确点击才复制。移除保留 revision 和审计，额度隐藏，之后可重新设置。未来月份可设置计划额度并标注未开始；不把未来月份当成发生了零消费。预算只影响展示，不改变账户或交易。

## 实现与兼容

领域日期、覆盖、聚合和比例计算在纯 Python 中；服务在同一 SQLite 读快照计算主指标、对比、趋势及排行。前端只访问版本化接口，金额十进制字符串／BigInt，不用浮点算账。schema v5 新增 category_budgets，唯一月份＋分类，额度 nullable（移除），revision 事务更新、幂等与审计；复制上月绑定账本版本。升级前验证备份，兼容 v1～v5 恢复；备份校验预算月份、分类方向、额度和版本。

## 必须验证

- 日周月年边界、跨年周、闰年、当前截断和上期对齐；无资料／上期为零，未来期间拒绝。
- 独立手算收入、支出、退款、费用、结余、分类占比和日均；本金及作废不参与。
- 汇总覆盖不重复；截取历史区间时未知与已知小计分离；月与年准确合计，日趋势不伪造。
- 预算默认无额度输出，配置后显示；修改、移除、重新设置、未来月份、超支、退款下限、按月隔离、复制不覆盖。
- 并发版本与幂等、写入失败回滚、迁移失败回滚、预算及历史来源备份实际恢复与篡改拒绝。
- 合成浏览器流程验证各周期、明细、导出、预算隐藏／设置／移除／复制和重启；无远程资源，桌面与窄屏不横向溢出。
