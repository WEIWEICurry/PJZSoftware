# 移除临时持仓归并工具（0.18.1）

## 验收条件

- 投资页面不再显示整理持仓归属入口，删除专用组件、服务与错误文案。
- 不再注册归并预览和提交接口，认证后的旧接口请求不再可调用，OpenAPI 不再包含这些路径。
- 保留 schema 10 和全部迁移，升级不执行数据清理。已经归并的金融事实、现金分录、操作审计、备份、计划及历史关联不改变。
- 支付账户与持仓账户继续独立；跨银行卡买入仍为同平台同标的一仓，卖出及定投正常。合成账本备份恢复后持仓与现金一致。
- 已有 0.18.0 用户使用同 schema 本地更新；0.17.x 及更早版本仍按 README 完整新包升级。

移除归并专属操作测试，保留独立支付计算测试，并增加接口已下线与持仓备份恢复回归。浏览器验证原入口不存在及既有操作流程。

## 本地验证

Ruff 检查与格式、mypy、264 项 pytest、前端格式／ESLint／类型检查／静态构建、5 项 Playwright、契约同步及应用自检均通过。移除工具专属测试后仍验证独立支付手算、已合并持仓的备份恢复和旧接口不可调用。成品及 CI 最终结果见 PR。
