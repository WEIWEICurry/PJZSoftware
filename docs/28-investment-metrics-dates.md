# 投资指标、交易净值日与日期操作

## 验收条件

- 持仓盈亏后依次显示持仓收益率、累计盈亏、累计收益率，三列均可正反排序；未知值最后。
- 持仓收益率=未实现盈亏/剩余成本；累计盈亏=未实现+已实现+现金分红+再投分红；累计收益率=累计盈亏/期初成本及后续累计投入（含费用，卖出不减分母）。非年化，成本未知或零分母显示未知。
- 新投资默认未归档支付宝账户、实际扣款/到账口径；费用直接显示，空白按零；编辑保留原数据。
- 买入蓝、卖出红、关联真实定投的买入显示紫色“定投买入”；作废状态保持普通文字。
- 买卖持久化净值所属日，新手工记录默认跟随确认日，手动修改后独立；历史优先保留定投已知日，否则回填确认日并标记默认补齐，允许修订。
- 确认日、手工净值所属日、定投核对范围/逐项确认日/净值日、手动估值日支持前后自然日；空日期点击填今天并遵守上下限。
- schema 11 事务迁移，升级前保护备份；不改旧交易金额、份额或入账日。恢复支持旧版升级和新版还原。

## 升级边界

旧版更新器仅支持同 schema。本版需完整解压运行新程序，自动保护备份及升级，之后重新设置 schema 11 固定入口；旧程序不打开升级账本。回退使用升级前备份恢复独立副本。
